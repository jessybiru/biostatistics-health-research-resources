
# Python Programming & Health Data Science Resources

A curated collection of freely accessible Python learning resources, including online textbooks, tutorials, statistical programming guides, datasets and practical exercises for biostatistics, epidemiology, data science and health research.


### 1. Python for Data Analysis (3rd Edition)

**Author:** Wes McKinney  
**Level:** Beginner to intermediate  
**Resource:** [Read the free online book](https://wesmckinney.com/book/)

An open-access online edition of the practical Python data analysis textbook written by the creator of pandas.

**Includes:**
- Python and Jupyter Notebook fundamentals
- Data cleaning and transformation using pandas
- Working with NumPy arrays
- Merging, reshaping and summarising datasets
- Data visualisation and time series analysis
- Code examples and supporting datasets on GitHub

**Best for:** Researchers and analysts transitioning from R, Stata, SAS or Excel to Python.

**Note:** The book is free to read online. The complete book text is not licensed for redistribution.

### 2. Think Stats (3rd Edition)

**Author:** Allen B. Downey  
**Level:** Beginner to intermediate  
**Resource:** [Access Think Stats](https://greenteapress.com/wp/think-stats-3e/)

An applied introduction to probability and statistics using Python, with an emphasis on learning through real data and computational exercises.

**Includes:**
- Executable Jupyter notebooks
- Google Colab compatibility
- Exploratory data analysis
- Probability distributions and statistical inference
- Regression and statistical modelling
- Exercises and code examples

**Best for:** Students and health researchers who want to learn statistical concepts while developing Python programming skills.

### 3. An Introduction to Statistical Learning with Applications in Python

**Authors:** Gareth James, Daniela Witten, Trevor Hastie, Robert Tibshirani and Jonathan Taylor  
**Level:** Intermediate  
**Textbook:** [Official website](https://www.statlearning.com/)  
**Practical labs:** [Python labs and datasets](https://intro-stat-learning.github.io/ISLP/labs.html)

A freely accessible statistical learning textbook with practical Python labs demonstrating commonly used predictive modelling methods.

**Includes:**
- Linear and logistic regression
- Cross-validation and bootstrap methods
- Regularisation and variable selection
- Classification and tree-based methods
- Support vector machines and deep learning
- Survival analysis
- Unsupervised learning
- Downloadable lab materials and datasets

**Best for:** Researchers, postgraduate students and analysts interested in statistical learning and predictive modelling.

### 4. statsmodels: Statistical Analysis Examples

**Provider:** statsmodels development team  
**Level:** Intermediate  
**Resource:** [Explore the examples](https://www.statsmodels.org/stable/examples/index.html)

A collection of practical examples demonstrating statistical analysis and modelling using Python.

**Includes:**
- Linear and logistic regression
- Generalised linear models
- Regression diagnostics
- Mixed-effects models
- Time series analysis
- Statistical tests and model interpretation
- Downloadable Python scripts and Jupyter notebooks

**Best for:** Biostatisticians and researchers who want to perform classical statistical analyses using Python.

### 5. lifelines: Survival Analysis in Python

**Provider:** lifelines project  
**Level:** Intermediate  
**Resource:** [Access the documentation and tutorials](https://lifelines.readthedocs.io/en/latest/)

A Python library with practical documentation and examples for analysing time-to-event data.

**Includes:**
- Kaplan–Meier survival estimation
- Cox proportional hazards regression
- Survival curves and model interpretation
- Time-varying covariates
- Proportional hazards assumption checks
- Model diagnostics and prediction

**Best for:** Clinical researchers, epidemiologists and postgraduate students conducting survival analysis.

### 6. PyHealth: Clinical Prediction Tutorials

**Provider:** PyHealth development team  
**Level:** Intermediate to advanced  
**Resource:** [Access the tutorials](https://pyhealth.readthedocs.io/en/latest/tutorials.html)

A collection of practical Python tutorials for developing and evaluating machine learning models using healthcare data.

**Includes:**
- Google Colab notebooks
- Public and synthetic healthcare datasets
- In-hospital mortality prediction
- Logistic regression, XGBoost and neural networks
- Model discrimination and calibration
- Confidence intervals and subgroup analysis
- Model interpretation using SHAP
- Patient-level data splitting and leakage prevention

**Best for:** Health researchers interested in clinical prediction modelling and healthcare machine learning.

**Note:** Start with the current PyHealth tutorial series rather than older examples written for previous versions.

### 7. scikit-learn: Practical Machine Learning Examples

**Provider:** scikit-learn development team  
**Level:** Intermediate  
**Resource:** [Explore the example gallery](https://scikit-learn.org/stable/auto_examples/index.html)

An extensive collection of worked Python examples demonstrating machine learning methods and model evaluation.

**Includes:**
- Classification and regression
- Cross-validation and hyperparameter tuning
- Feature selection and preprocessing
- Clustering and dimensionality reduction
- Model evaluation and visualisation
- Reproducible Python code

**Best for:** Researchers and analysts learning predictive modelling with Python.
