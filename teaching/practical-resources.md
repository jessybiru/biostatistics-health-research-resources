
# Teaching & Practical Resources

A curated collection of freely accessible teaching and practical learning materials for biostatistics, epidemiology, statistical programming and health research.

These resources include teaching guides, statistical datasets, practical exercises, workshops, reproducible code and classroom-ready learning materials.

They are intended for lecturers, postgraduate students, researchers and professionals who want to strengthen their statistical skills through hands-on learning.

### 1. Statistical Practice in Epidemiology using R (SPE-R)

**Provider:** SPE-R course team  
**Software:** R  
**Level:** Intermediate  
**Resource:** [Access the course materials](https://spe-r.github.io/)  
**Source code:** [GitHub repository](https://github.com/SPE-R/SPE)

A comprehensive practical course for learning and teaching statistical methods in epidemiology.

**Includes:**
- Lecture slides
- Practical exercises booklet
- Separate booklet with worked solutions
- Downloadable datasets
- R scripts and functions
- Course setup instructions
- Downloadable course materials

**Best for:** Epidemiology lecturers, postgraduate students and researchers looking for structured statistical practicals.

### 2. Data Carpentry: Social Sciences

**Provider:** The Carpentries  
**Software:** R, spreadsheets and OpenRefine  
**Level:** Beginner  
**Resource:** [Access the lessons](https://www.datacarpentry.org/lessons/)

A collection of reusable teaching materials introducing researchers to data organisation, cleaning and analysis.

**Includes:**
- Spreadsheet data organisation
- Data cleaning using OpenRefine
- Data analysis and visualisation using R
- Practical exercises
- Example datasets
- Instructor notes and teaching guidance

**Best for:** Lecturers and researchers teaching introductory data management and statistical programming.

**Note:** The Social Sciences curriculum uses survey data from farming households in eastern Africa.

### 3. OpenIntro Statistics

**Authors:** David M. Diez, Mine Çetinkaya-Rundel and Christopher D. Barr  
**Level:** Beginner to intermediate  
**Resource:** [Access the free textbook](https://www.openintro.org/book/os/)

An introductory statistics textbook designed for classroom teaching and independent learning.

**Includes:**
- Free textbook PDF
- Statistical exercises
- Learning objectives
- Worked examples
- Companion datasets
- Supporting teaching resources

**Best for:** Undergraduate students, postgraduate beginners and lecturers teaching introductory statistics.

### 4. OpenIntro Statistical Datasets

**Provider:** OpenIntro  
**Software:** R, Stata, SAS, Python and spreadsheets  
**Level:** All levels  
**Resource:** [Browse the datasets](https://www.openintro.us/data/)

A collection of datasets suitable for classroom demonstrations, statistical exercises and independent learning.

**Includes:**
- Downloadable CSV datasets
- Tab-delimited files
- R data files
- Datasets covering health, education, social and economic topics
- Data used in OpenIntro textbooks

**Best for:** Lecturers looking for accessible datasets for teaching statistical methods.

### 5. UCLA Statistical Consulting Resources

**Provider:** UCLA Office of Advanced Research Computing  
**Software:** R, Stata, SAS and other statistical packages  
**Level:** Beginner to advanced  
**Resource:** [Explore the learning resources](https://stats.oarc.ucla.edu/)

A comprehensive collection of statistical tutorials and practical examples.

**Includes:**
- Statistical learning modules
- Annotated statistical output
- Data analysis examples
- Regression tutorials
- Survival analysis workshops
- Missing-data tutorials
- Multilevel modelling examples
- Example code and datasets

**Best for:** Lecturers, postgraduate students and researchers looking for reproducible examples of statistical methods.

### 6. The Carpentries: Programming and Data Skills Lessons

**Provider:** The Carpentries  
**Software:** R, Python, spreadsheets, SQL and other tools  
**Level:** Beginner to intermediate  
**Resource:** [Explore the lesson library](https://www.carpentries.org/lessons/)

An extensive collection of collaboratively developed lessons for teaching research computing and data skills.

**Includes:**
- Programming lessons
- Data cleaning and organisation
- Data visualisation
- Reproducible research workflows
- Practical exercises
- Instructor guidance
- Links to source repositories

**Best for:** Researchers and lecturers preparing hands-on workshops in statistical programming and research data management.
