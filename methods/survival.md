
# Survival Analysis Resources

A curated collection of freely accessible learning resources covering survival analysis and time-to-event data methods, with applications in biostatistics, epidemiology, clinical research and public health.

Topics include Kaplan–Meier estimation, log-rank tests, Cox proportional hazards regression, model diagnostics and practical survival analysis using statistical software.

These resources include online course materials, tutorials, worked examples, datasets and practical exercises.

### 1. Design and Analysis of Clinical Trials

**Provider:** Pennsylvania State University  
**Level:** Intermediate  
**Resource:** [Access the free course notes](https://online.stat.psu.edu/stat509/)

A course on statistical methods for clinical trials, including time-to-event outcomes.

**Includes:** Clinical trial design, survival analysis concepts, statistical inference and worked examples.

**Best for:** Clinical researchers and postgraduate students interested in survival outcomes within clinical trials.

### 2. Introduction to Survival Analysis in R

**Provider:** UCLA Office of Advanced Research Computing  
**Level:** Intermediate  
**Resource:** [Access the R survival analysis seminar](https://stats.oarc.ucla.edu/r/seminars/introduction-to-survival-analysis-in-r/)

A practical introduction to survival analysis using R.

**Includes:** Kaplan–Meier estimation, log-rank tests, Cox proportional hazards regression, survival plots, model diagnostics and R code.

**Best for:** Researchers analysing time-to-event data in R.

### 3. Survival Analysis with Stata

**Provider:** UCLA Office of Advanced Research Computing  
**Level:** Intermediate  
**Resource:** [Access the Stata survival analysis seminar](https://stats.oarc.ucla.edu/stata/seminars/stata-survival/)

An applied survival analysis seminar using a substance-use treatment dataset.

**Includes:** Kaplan–Meier curves, log-rank tests, Cox regression, proportional hazards assessment, model diagnostics and time-varying covariates.

**Best for:** Epidemiologists and clinical researchers using Stata.

### 4. Introduction to Survival Analysis in SAS

**Provider:** UCLA Office of Advanced Research Computing  
**Level:** Intermediate  
**Resource:** [Access the SAS survival analysis seminar](https://stats.oarc.ucla.edu/sas/seminars/sas-survival/)

A practical seminar using data from 500 participants in the Worcester Heart Attack Study.

**Includes:** Downloadable data, PROC LIFETEST, PROC PHREG, Kaplan–Meier estimation, Cox regression, model diagnostics and time-varying covariates.

**Best for:** Researchers performing survival analysis in SAS.

### 5. lifelines: Survival Analysis in Python

**Provider:** lifelines development team  
**Level:** Intermediate  
**Resource:** [Access the documentation](https://lifelines.readthedocs.io/en/latest/)

An open-source Python library for survival analysis.

**Includes:** Kaplan–Meier estimation, Cox regression, parametric survival models, time-varying covariates and model diagnostics.

**Best for:** Researchers interested in performing time-to-event analysis using Python.
