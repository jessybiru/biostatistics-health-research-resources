# Missing Data Resources

A curated collection of freely accessible learning resources covering missing-data methods and their applications in biostatistics, epidemiology and health research.

Topics include missing-data mechanisms (MCAR, MAR and MNAR), complete-case analysis, multiple imputation, missing-data diagnostics and sensitivity analysis.

These resources include online textbooks, statistical tutorials, worked examples, datasets and practical exercises using R, Stata and other statistical software.
