# Missing Data Resources

A curated collection of freely accessible learning resources covering missing-data methods and their applications in biostatistics, epidemiology and health research.

Topics include missing-data mechanisms (MCAR, MAR and MNAR), complete-case analysis, multiple imputation, missing-data diagnostics and sensitivity analysis.

These resources include online textbooks, statistical tutorials, worked examples, datasets and practical exercises using R, Stata and other statistical software.

### 1. Flexible Imputation of Missing Data (2nd Edition)

**Author:** Stef van Buuren  
**Level:** Intermediate to advanced  
**Resource:** [Read the free online book](https://stefvanbuuren.name/fimd/)

A comprehensive textbook on statistical methods for handling incomplete data, with an emphasis on multiple imputation.

**Includes:**
- MCAR, MAR and MNAR mechanisms
- Missing-data patterns and diagnostics
- Multiple imputation by chained equations (MICE)
- Predictive mean matching
- Multilevel and longitudinal missing data
- Imputation model specification
- Pooling estimates using Rubin's rules
- Sensitivity analysis
- Worked examples and R code

**Best for:** Biostatisticians, epidemiologists, postgraduate students and researchers handling missing data in observational or clinical studies.

### 2. Analysis with Missing Data: R Practical Exercises

**Provider:** University of Copenhagen, Section of Biostatistics  
**Level:** Intermediate  
**Resource:** [Access the practical exercises](https://biostatistics.dk/teaching/advtopics/missing.html)

A hands-on teaching module introducing missing-data concepts and methods using R.

**Includes:**
- MCAR, MAR and MNAR
- Complete-case analysis
- Multiple imputation using MICE
- Comparison of complete-case and imputed analyses
- Downloadable example data
- R code and exercises
- Lecture slides and recommended reading

**Best for:** Students and researchers who want practical experience implementing multiple imputation in R.

### 3. amices: Missing Data Learning Resources

**Provider:** amices project  
**Level:** Intermediate to advanced  
**Resource:** [Explore the resources](https://amices.org/)

A collection of learning materials and software resources for analysing incomplete datasets using multiple imputation.

**Includes:**
- Tutorials on the MICE algorithm
- Convergence and pooling
- Missingness diagnostics
- Passive imputation
- Multilevel imputation
- Sensitivity analysis
- R package documentation and code examples

**Best for:** R users interested in developing more advanced missing-data analysis skills.

### 5. Multiple Imputation in SAS

**Provider:** UCLA Office of Advanced Research Computing  
**Level:** Intermediate to advanced  
**Resource:** [Access the SAS workshop](https://stats.oarc.ucla.edu/sas/seminars/multiple-imputation-in-sas/mi_new_1/)

An applied workshop demonstrating methods for handling missing data using SAS.

**Includes:**
- Missing-data mechanisms
- Complete-case analysis
- Multiple imputation
- PROC MI
- Imputation model specification
- Worked SAS examples
- Downloadable example data and presentation materials

**Best for:** Clinical researchers and statisticians using SAS for missing-data analysis.

**Important reminder:** Multiple imputation is not automatically appropriate for every missing-data problem. The choice between complete-case analysis, multiple imputation, maximum likelihood and sensitivity analyses should depend on the estimand, study design, missingness assumptions and analysis model. In particular, MAR cannot generally be verified from observed data alone.
