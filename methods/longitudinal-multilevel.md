
# Longitudinal & Multilevel Analysis Resources

A curated collection of freely accessible learning resources covering longitudinal data analysis, repeated measurements, hierarchical data structures and multilevel statistical modelling.

Topics include mixed-effects models, random intercepts and slopes, intraclass correlation coefficients, repeated-measures analysis and model interpretation.

These resources include university course materials, statistical tutorials, worked examples, datasets and practical exercises using R, Stata and other statistical software.

### 1. Analyzing Longitudinal Data Using Multilevel Modeling

**Provider:** UCLA Office of Advanced Research Computing  
**Level:** Intermediate  
**Resource:** [Access the seminar](https://stats.oarc.ucla.edu/other/mult-pkg/seminars/mlm-longitudinal/)

A practical introduction to multilevel approaches for analysing repeated observations over time.

**Includes:**
- Repeated measures ANOVA versus mixed models
- Longitudinal growth models
- Random intercepts and slopes
- Changes in outcomes over time
- Modelling treatment effects over time
- Examples using HLM, SAS and other software

**Best for:** Researchers analysing cohort studies, repeated measurements and longitudinal intervention data.

### 2. An Introduction to Linear Mixed-Effects Modeling in R

**Author:** Violet A. Brown
**Level:** Beginner to intermediate  
**Resource:** [Read the open-access tutorial](https://doi.org/10.1177/2515245920960351)  
**Code and data:** [Access the OSF materials](https://osf.io/v6qag/)

A published tutorial introducing the theory and practical implementation of linear mixed-effects models using R.

**Includes:**
- Fixed and random effects
- Model specification
- Fitting mixed-effects models in R
- Interpretation of model output
- Worked examples
- Downloadable data and R scripts

**Best for:** Researchers with basic regression knowledge who are new to mixed-effects modelling.

### 3. CRAN Task View: Mixed, Multilevel and Hierarchical Models

**Provider:** Comprehensive R Archive Network (CRAN)  
**Level:** Intermediate to advanced  
**Resource:** [Explore the task view](https://cran.r-project.org/web/views/MixedModels.html)

A reference guide to R packages for fitting multilevel, hierarchical and mixed-effects models.

**Includes:**
- Linear mixed-effects models
- Generalised linear mixed models
- Nested and crossed random effects
- Frequentist and Bayesian approaches
- Links to packages such as lme4, nlme and glmmTMB

**Best for:** R users selecting appropriate software packages for hierarchical or repeated-measures data.

### 4. Multilevel and Longitudinal Modelling Using Stata

**Provider:** StataCorp  
**Level:** Intermediate  
**Resource:** [Watch the free webinar](https://www.stata.com/training/webinar_series/multilevel-mixed-effects-models/)

A recorded webinar demonstrating how to analyse nested and longitudinal data using Stata.

**Includes:**
- Random-intercept and random-slope models
- Linear mixed-effects models
- The mixed command
- Predictions and visualisation
- Introduction to models for categorical and count outcomes
- Downloadable webinar materials

**Best for:** Researchers working with clustered, hierarchical or longitudinal data in Stata.

### 5. EasyLME: Longitudinal Data Analysis

**Authors:** Jessica Murphy, Nicholas Weaver and Audrey Hendricks  
**Institution:** University of Colorado Denver  
**Level:** Beginner to intermediate  
**Resource:** [Open the EasyLME application](https://shiny.clas.ucdenver.edu/EasyLME/)

An interactive web application for analysing longitudinal data using linear mixed-effects models in R.

**Includes:**
- Descriptive summaries
- Longitudinal exploratory plots
- Mixed-effects model results
- Likelihood-ratio tests for nested models
- Model diagnostic plots
- Fitted trajectories

**Best for:** Researchers exploring longitudinal mixed-effects models through an interactive interface.

**Note:** The application assumes continuous outcome and time variables, so it is not suitable for every longitudinal analysis.

**Methodological note:** Longitudinal data and multilevel data are related but not identical. Model selection should consider the study design, outcome distribution, clustering structure, within-subject correlation, missing-data assumptions and research estimand.
